# 🗼 Tokyo Food Finder

A self-contained, mobile-friendly Leaflet map of Tokyo's best restaurants,
combining **Tabelog** (3.55+) and **Google Places** (4.2+, 100+ reviews)
ratings with **live opening hours** and an **"Open now (Japan)"** filter.

**Live site:** https://drdanieldem-hub.github.io/tokyo-food-finder/

---

## What's in the repo

| File / dir | What it is |
|---|---|
| `index.html` | **The whole app.** Self-contained — no build step needed to run, all data + JS + CSS inlined. Generated by `build.py`. |
| `build.py` | Generator: reads `final_restaurants_with_hours.json` → writes `index.html`. Run this whenever the data changes. |
| `final_restaurants_with_hours.json` | The current dataset. 3,921 restaurants, 3,819 with Google-verified opening hours. |
| `popup_test.html` | Standalone harness for visually verifying popup HTML without the full map. |
| `app.html`, `tokyo-restaurants.html`, `tokyo-restaurants-live.html` | Earlier iterations, kept for reference. Not served. |
| `scraper/` | The data pipeline that produced the JSON. See `scraper/README.md`. |
| `sw.js`, `manifest.json`, `icon-*.png` | PWA bits (install-to-homescreen, offline shell). |

## Features

- **3,921 curated restaurants** in central Tokyo (combined Tabelog + Google filter)
- **Dual-rating popups** — Tabelog + Google side-by-side, with deep links
- **Live opening hours** from Google Place Details, displayed per-day in the popup
- **"Open now (Japan)" filter** — time-synchronised, recomputed every 30s, anchored
  to Asia/Tokyo regardless of the user's timezone. Restaurants with no hours data
  are excluded from this filter (we can't verify they're open).
- **Auto-locate** — the map requests the user's location ~0.8s after load, pans
  there, and keeps a red dot tracking them. Tap the 📍 button to stop/restart.
- **"Next opening" hint** for closed places (e.g. "Next: tomorrow at 17:00")
- **Filters:** Tabelog rating floor, Google rating floor, min review count,
  cuisine multi-select, area text search, top-picks-only
- **Dark mode** toggle (persisted in localStorage)
- **Walking distance + time** from user to each restaurant when GPS is on
- **Mobile-first** with a collapsible sidebar and PWA install support

## Regenerate the site

```bash
cd ~/tokyo-food-finder
python3 build.py                # rewrites index.html from the current JSON
```

Then `git add -A && git commit -m "..." && git push origin main` — GitHub
Pages serves `main` automatically.

To bump the data, see `scraper/README.md` for the full pipeline (Stage 1:
Tabelog list scrape, Stage 2: detail enrichment, Stage 3: Google cross-ref,
Stage 4: Google hours enrichment).

## Tech notes

- **No build system** — `build.py` is a plain string concatenation that writes a
  fully self-contained HTML file with the GeoJSON, marker metadata, and all JS
  inlined. Total size ≈ 4.7 MB.
- **Time handling:** `getTokyoMinutesNow()` uses `Intl.DateTimeFormat` with
  `timeZone: 'Asia/Tokyo'` so the "open now" computation is always correct
  relative to Tokyo, not the user's device clock.
- **Service worker** is a tiny offline-shell only; the data is too large to
  cache fully. The site requires network on first load.
- **No analytics, no third-party trackers** — only the OpenStreetMap/CARTO tile
  providers (loaded from their public CDNs).
